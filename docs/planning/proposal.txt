Our team would like to share our project proposal.
1) Industry / Application Domain
	•	Biomedical research
	•	Computational pathology
	•	Spatial transcriptomics
	•	Digital pathology
	•	AI-assisted scientific discovery
Our project focuses on using AI to help researchers better understand spatial omics data from tissue images.
2) Real-World Problem Statement
	•	Spatial transcriptomics can measure gene expression across many locations in a tissue sample.
	•	It also produces large histopathology images that show the structure of the tissue.
	•	However, interpreting this type of data is difficult because researchers often need to:
	◦	examine the tissue image,
	◦	identify important tissue regions,
	◦	analyze gene expression in those regions,
	◦	connect genes to biological pathways,
	◦	search PubMed for related studies, and
	◦	combine all of this information into a biological explanation.
The main problem is that the data and the knowledge are disconnected. A researcher may find an interesting region of interest (ROI) in a tissue image, but it is not easy to quickly know which genes are important in that region, what pathways are involved, or what the literature says about similar findings.
Our project aims to solve this by building an AI-powered Spatial Omics Copilot inside a spatial omics visualization tool. The user can select an ROI on the tissue image, and the system will help generate a biologically grounded explanation using gene expression, pathway information, and PubMed literature.
The AI copilot will use a Retrieval-Augmented Generation (RAG) workflow. After a user selects an ROI, the system will automatically retrieve relevant pathway information and PubMed abstracts, then provide this retrieved context to a large language model to generate a more reliable interpretation.

	•	Biomedical text abstracts from PubMed
4) Desired Outcomes
By the end of the project, we aim to build a working prototype of an AI-powered spatial omics visualization system.
The system should allow users to:
	•	Load and view a whole-slide histopathology image.
	•	Overlay spatial gene expression data on the tissue image.
	•	Draw a region of interest (ROI) on a tissue area they want to study.
	•	Analyze gene expression inside the selected ROI.
	•	Identify important genes in that region.
	•	Connect those genes to relevant biological pathways.
	•	Use an agentic RAG pipeline, managed with LangGraph, to decide which tools to call based on the selected ROI and user question. These tools may include gene expression analysis, pathway enrichment, and PubMed retrieval.
	•	Pass the retrieved context to an LLM, such as Ollama or ChatGPT, to generate a biologically grounded interpretation.
	•	Ask follow-up questions through a chat interface.
The final goal is not just to display spatial omics data, but to help researchers understand what a selected tissue region may mean biologically.
We plan to use tools such as:
	•	Dash or Flask for the visualization interface
	•	LangChain and LangGraph for the RAG workflow
	•	Ollama or ChatGPT as the large language model
	•	PubMed API for literature retrieval
	•	Pathway resources such as KEGG and Gene Ontology
We will evaluate the system based on:
	•	Whether the generated biological explanations make sense
	•	Whether the retrieved PubMed papers are relevant
	•	Whether the system responds in a reasonable time
	•	Whether the interface is clear and easy to use
